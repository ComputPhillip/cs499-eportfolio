Run and verify

Extract a milestone ZIP and open its milestone folder. Use Python 3.10 or newer with Tkinter. These desktop applications do not run inside the portfolio page.

python run_checkers.py
python -m unittest discover -s tests -v

Read the selected milestone’s README for database usage, benchmark commands, and known limitations. SHA-256 artifact manifest records the packaged files.

Attribution

Original graphics.py identifies John Zelle as author and includes its license terms, preserved in the original package. Enhanced rendering uses Tkinter directly.
