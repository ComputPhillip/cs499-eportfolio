Artifact and Purpose

I selected the graphical Python checkers project associated with my IT 450 coursework to demonstrate how database design can support an interactive application. The source baseline, Checkers_v24.py, was supplied on November 1, 2026; its original creation date is not established. The database enhancement builds on the separately preserved software design and algorithms milestones. It was implemented on November 1, 2026, and retains the graphical interface and minimax opponent.

The original application saves one position to a fixed text file. The software design milestone introduced validated JSON files, but users still had to manage individual files and some session details were omitted. The database milestone adds a named SQLite position library with create, list, load, replace, and delete operations. This gives the graphical application a practical way to revisit positions while preserving the earlier artifact versions for comparison.

Design Choices and Portfolio Value

I chose a relational position library because a saved game has one set of descriptive fields and many pieces. The saved_games table holds the name, turn, optional forced-capture coordinates, winner, opponent mode, search depth, and timestamps. The pieces table holds coordinates, color, and king status for each saved game. Its composite primary key combines game identifier and coordinates, preventing two pieces from occupying the same square in one saved position.

The foreign key links pieces to their saved game and cascades deletions. A unique name constraint prevents an accidental second record with the same name, while an index supports ordering the library by recent updates. Separating game metadata from its pieces avoids repeating the same session values in every piece record. The design also makes it possible to count pieces in the library listing without loading the entire graphical application.

This enhancement supports my computer graphics focus by restoring the data that determines what the player sees and how the interface behaves. A restored record includes opponent mode and search depth as well as the board. It can preserve a forced continuation or a resigned result. JSON import and export remain available for exchanging positions, while SQLite supports an organized local collection. The database stores snapshots, not a complete sequence of moves or a replay system.

Integrity and Security Decisions

A central lesson is that a database transaction must match the user action. Replacing a saved position changes both the parent record and its pieces. Those writes occur in one transaction, so an error during piece insertion rolls back the whole replacement. Otherwise, a displayed success message could conceal a partially updated save. Loading also uses a consistent read transaction so metadata and piece rows come from one database snapshot.

The repository layer binds user values through SQL parameters. A saved name is therefore handled as data instead of being inserted into SQL syntax. Schema checks constrain board coordinates, piece colors, king values, turn values, search depths, and paired forced-capture coordinates. Application validation handles rules that span rows, such as piece counts and legal capture continuation, before a loaded position reaches the controller.

These controls serve different purposes. Parameter binding addresses injection through query values; constraints protect row integrity; game validation checks whether the reconstructed position is usable. Schema version 1 is recorded with PRAGMA user_version, and unknown versions are rejected rather than silently interpreted. The library is local and has no encryption, account system, or access-control service. Protecting the file still depends on operating-system permissions and responsible handling of saved data.

Validation and Learning

The database regression run passed 31 tests: 20 inherited checks and 11 added database or library-interface checks. The added coverage exercises persistence across reopened connections, create/read/update/delete behavior, capture continuation, resignation, duplicate names, invalid state, schema constraints, missing records, and rejection of an unknown schema version. An injection-shaped name remains a literal name and does not remove a table.

The most useful failure-path check installs a test trigger that rejects piece insertion during replacement. After the replacement fails, the saved name and board still match their previous values. This demonstrates rollback for that injected failure; it does not simulate every power-loss or storage-failure scenario. Other checks remove all piece rows or bypass schema checks to insert invalid king or forced-capture fields. Loading rejects these damaged records instead of passing them to the interface.

Two Tk integration checks exercise the library controls, including restoring opponent mode and depth and canceling or confirming deletion. These tests provide evidence for the paths they execute, not proof of complete usability or every possible interaction. A broader manual review remains valuable, particularly with many saved positions and a busy interface.

The main design challenge was preserving one coherent position across the database, game model, and controller. The model already knew how to validate board state, so the repository could reuse that boundary instead of creating a second, inconsistent rules engine. The trade-off is that persistence remains coupled to the current model contract. Future rule changes or schema upgrades will require an explicit migration and compatibility plan. Short synchronous SQLite operations keep this local design understandable, but larger collections or slow storage would justify further responsiveness measurements.

"""SQLite position library. One transaction replaces a parent and all its pieces."""
from contextlib import contextmanager
from dataclasses import dataclass
from pathlib import Path
import sqlite3

from . import storage
from .model import Game

SCHEMA_VERSION = 1
MODES = ('Two players', 'Computer Black', 'Computer White')

SCHEMA = """
CREATE TABLE IF NOT EXISTS saved_games (
    id INTEGER PRIMARY KEY,
    name TEXT NOT NULL UNIQUE CHECK(length(trim(name)) BETWEEN 1 AND 80),
    turn TEXT NOT NULL CHECK(turn IN ('White','Black')),
    forced_x INTEGER, forced_y INTEGER,
    winner TEXT CHECK(winner IN ('White','Black')),
    opponent TEXT NOT NULL CHECK(opponent IN ('Two players','Computer Black','Computer White')),
    depth INTEGER NOT NULL CHECK(depth BETWEEN 1 AND 4),
    created_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ','now')),
    updated_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ','now')),
    CHECK((forced_x IS NULL AND forced_y IS NULL) OR
          (forced_x IS NOT NULL AND forced_y IS NOT NULL AND
           forced_x BETWEEN 0 AND 7 AND forced_y BETWEEN 0 AND 7 AND (forced_x+forced_y)%2=0))
);
CREATE TABLE IF NOT EXISTS pieces (
    game_id INTEGER NOT NULL REFERENCES saved_games(id) ON DELETE CASCADE,
    x INTEGER NOT NULL CHECK(x BETWEEN 0 AND 7),
    y INTEGER NOT NULL CHECK(y BETWEEN 0 AND 7),
    color TEXT NOT NULL CHECK(color IN ('White','Black')),
    king INTEGER NOT NULL CHECK(king IN (0,1)),
    PRIMARY KEY(game_id,x,y),
    CHECK((x+y)%2=0),
    CHECK(king=1 OR NOT ((color='White' AND y=7) OR (color='Black' AND y=0)))
);
CREATE INDEX IF NOT EXISTS games_recent ON saved_games(updated_at DESC,id DESC);
"""


@dataclass(frozen=True)
class SavedPosition:
    id: int
    name: str
    game: Game
    opponent: str
    depth: int


class PositionLibrary:
    def __init__(self, path):
        self.path = Path(path)
        self.path.parent.mkdir(parents=True, exist_ok=True)
        with self._connection() as conn:
            version = conn.execute('PRAGMA user_version').fetchone()[0]
            if version not in (0, SCHEMA_VERSION):
                raise ValueError('Unsupported database schema version.')
            if version == 0:
                # Refuse to reinterpret an unrelated database as a checkers library.
                tables = conn.execute("SELECT name FROM sqlite_master WHERE type='table'").fetchall()
                if tables:
                    raise ValueError('This file is not a checkers position library.')
                conn.executescript('BEGIN;\n' + SCHEMA + '\nPRAGMA user_version=1;\nCOMMIT;')
            # Check expected columns before creating a dialog for this file.
            conn.execute('SELECT id,name,turn,forced_x,forced_y,winner,opponent,depth,created_at,updated_at FROM saved_games LIMIT 0')
            conn.execute('SELECT game_id,x,y,color,king FROM pieces LIMIT 0')

    @contextmanager
    def _connection(self):
        conn = sqlite3.connect(self.path, timeout=2)
        conn.row_factory = sqlite3.Row
        conn.execute('PRAGMA foreign_keys=ON')
        try:
            with conn:
                yield conn
        finally:
            conn.close()

    @staticmethod
    def _validated(game, opponent, depth):
        if opponent not in MODES or type(depth) is not int or not 1 <= depth <= 4:
            raise ValueError('Invalid opponent or search depth.')
        data = dict(version=1, turn=game.turn, forced=list(game.forced) if game.forced else None,
                    pieces=[dict(x=x,y=y,color=p.color,king=p.king) for (x,y),p in game.board.items()])
        clean = storage.validate(data)
        if game.winner not in (None,'White','Black'):
            raise ValueError('Invalid winner.')
        if clean.winner is not None and game.winner not in (None,clean.winner):
            raise ValueError('Winner conflicts with the terminal board.')
        if game.winner and game.forced:
            raise ValueError('A finished position cannot require another capture.')
        clean.winner = game.winner or clean.winner
        return clean

    def save(self, name, game, opponent='Two players', depth=3, position_id=None):
        if not isinstance(name,str) or not 1 <= len(name.strip()) <= 80:
            raise ValueError('Use a name containing 1 to 80 characters.')
        name = name.strip()
        clean = self._validated(game,opponent,depth)
        fx,fy = clean.forced or (None,None)
        fields = (name,clean.turn,fx,fy,clean.winner,opponent,depth)
        with self._connection() as conn:
            if position_id is None:
                cursor = conn.execute('INSERT INTO saved_games(name,turn,forced_x,forced_y,winner,opponent,depth) VALUES(?,?,?,?,?,?,?)',fields)
                position_id = cursor.lastrowid
            else:
                cursor = conn.execute("UPDATE saved_games SET name=?,turn=?,forced_x=?,forced_y=?,winner=?,opponent=?,depth=?,updated_at=strftime('%Y-%m-%dT%H:%M:%fZ','now') WHERE id=?",fields+(position_id,))
                if cursor.rowcount != 1:
                    raise KeyError('Saved position no longer exists.')
                conn.execute('DELETE FROM pieces WHERE game_id=?',(position_id,))
            conn.executemany('INSERT INTO pieces(game_id,x,y,color,king) VALUES(?,?,?,?,?)',
                             [(position_id,x,y,p.color,int(p.king)) for (x,y),p in sorted(clean.board.items())])
        return position_id

    def list_positions(self):
        with self._connection() as conn:
            return [dict(row) for row in conn.execute('''SELECT g.id,g.name,g.turn,g.winner,g.opponent,g.depth,g.updated_at,
                (SELECT count(*) FROM pieces p WHERE p.game_id=g.id) AS piece_count
                FROM saved_games g ORDER BY g.updated_at DESC,g.id DESC''')]

    def load(self, position_id):
        with self._connection() as conn:
            # Explicit transaction gives parent and child reads one consistent snapshot.
            conn.execute('BEGIN')
            row = conn.execute('SELECT * FROM saved_games WHERE id=?',(position_id,)).fetchone()
            if row is None:
                raise KeyError('Saved position no longer exists.')
            records = conn.execute('SELECT x,y,color,king FROM pieces WHERE game_id=? ORDER BY x,y',(position_id,)).fetchall()
            if any(type(r['king']) is not int or r['king'] not in (0,1) for r in records):
                raise ValueError('Invalid stored piece rank.')
            pieces = [dict(x=r['x'],y=r['y'],color=r['color'],king=bool(r['king'])) for r in records]
            if (row['forced_x'] is None) != (row['forced_y'] is None):
                raise ValueError('Incomplete stored capture continuation.')
            forced = None if row['forced_x'] is None else [row['forced_x'],row['forced_y']]
            game = storage.validate(dict(version=1,turn=row['turn'],forced=forced,pieces=pieces))
            game.winner = row['winner'] or game.winner
            clean = self._validated(game,row['opponent'],row['depth'])
            return SavedPosition(row['id'],row['name'],clean,row['opponent'],row['depth'])

    def delete(self, position_id):
        with self._connection() as conn:
            if conn.execute('DELETE FROM saved_games WHERE id=?',(position_id,)).rowcount != 1:
                raise KeyError('Saved position no longer exists.')

import sqlite3
import tempfile
import unittest
from pathlib import Path
from checkers.database import PositionLibrary
from checkers.model import Game, Piece, Move


class DatabaseTests(unittest.TestCase):
    def setUp(self):
        self.temp=tempfile.TemporaryDirectory()
        self.path=Path(self.temp.name)/'positions.sqlite3'
        self.library=PositionLibrary(self.path)

    def tearDown(self):self.temp.cleanup()

    def test_create_read_update_delete_across_connections(self):
        game=Game.standard()
        id=self.library.save('Opening',game,'Computer Black',4)
        reopened=PositionLibrary(self.path)
        saved=reopened.load(id)
        self.assertEqual((saved.game,saved.opponent,saved.depth),(game,'Computer Black',4))
        game.apply(game.legal_moves()[0])
        self.assertEqual(reopened.save('After one move',game,'Two players',2,id),id)
        self.assertEqual(reopened.load(id).game,game)
        self.assertEqual(reopened.list_positions()[0]['piece_count'],24)
        reopened.delete(id)
        self.assertEqual(reopened.list_positions(),[])
        with self.library._connection() as conn:self.assertEqual(conn.execute('SELECT count(*) FROM pieces').fetchone()[0],0)

    def test_capture_continuation_and_resignation_round_trip(self):
        game=Game({(0,0):Piece('White'),(1,1):Piece('Black'),(3,3):Piece('Black')})
        game.apply(Move((0,0),(2,2),(1,1)))
        id=self.library.save('Chain',game)
        self.assertEqual(self.library.load(id).game,game)
        resigned=Game.standard();resigned.winner='Black'
        id=self.library.save('Resigned',resigned)
        self.assertEqual(self.library.load(id).game.winner,'Black')
        self.assertEqual(self.library.load(id).game.legal_moves(),[])

    def test_names_are_bound_values_and_duplicates_do_not_overwrite(self):
        name="Robert'); DROP TABLE pieces;--"
        id=self.library.save(name,Game.standard())
        self.assertEqual(self.library.load(id).name,name)
        with self.assertRaises(sqlite3.IntegrityError):self.library.save(name,Game.standard())
        self.assertEqual(len(self.library.list_positions()),1)

    def test_failed_piece_write_rolls_back_replacement(self):
        original=Game.standard();id=self.library.save('Original',original)
        with self.library._connection() as conn:
            conn.execute("CREATE TRIGGER reject_piece BEFORE INSERT ON pieces BEGIN SELECT RAISE(ABORT,'test rejection'); END")
        altered=Game.standard();altered.apply(altered.legal_moves()[0])
        with self.assertRaises(sqlite3.IntegrityError):self.library.save('Changed',altered,position_id=id)
        saved=self.library.load(id)
        self.assertEqual((saved.name,saved.game),('Original',original))

    def test_schema_constraints_and_foreign_keys(self):
        with self.library._connection() as conn:
            with self.assertRaises(sqlite3.IntegrityError):
                conn.execute("INSERT INTO pieces VALUES(999,0,0,'White',0)")
        id=self.library.save('Valid',Game.standard())
        for values in [(id,1,0,'White',0),(id,8,0,'White',0),(id,0,0,'Orange',0),(id,0,0,'White',2)]:
            with self.subTest(values=values),self.library._connection() as conn:
                with self.assertRaises(sqlite3.IntegrityError):conn.execute('INSERT INTO pieces VALUES(?,?,?,?,?)',values)

    def test_invalid_state_and_missing_id_fail_without_mutation(self):
        for name,game,mode,depth in [('',Game.standard(),'Two players',3),('X',Game(),'Two players',3),
                                    ('X',Game.standard(),'Invalid',3),('X',Game.standard(),'Two players',True),
                                    ('X',Game.standard(),'Two players',5)]:
            with self.subTest(name=name,mode=mode,depth=depth),self.assertRaises(ValueError):self.library.save(name,game,mode,depth)
        with self.assertRaises(KeyError):self.library.load(42)
        with self.assertRaises(KeyError):self.library.delete(42)
        with self.assertRaises(KeyError):self.library.save('Missing',Game.standard(),position_id=42)
        self.assertEqual(self.library.list_positions(),[])

    def test_load_revalidates_tampered_cross_row_state(self):
        id=self.library.save('Corrupted',Game.standard())
        with self.library._connection() as conn:conn.execute('DELETE FROM pieces WHERE game_id=?',(id,))
        with self.assertRaises(ValueError):self.library.load(id)

    def test_unknown_schema_is_rejected(self):
        with self.library._connection() as conn:conn.execute('PRAGMA user_version=99')
        with self.assertRaises(ValueError):PositionLibrary(self.path)

    def test_load_rejects_bypassed_rank_and_continuation_constraints(self):
        id=self.library.save('Tampered',Game.standard())
        with self.library._connection() as conn:
            conn.execute('PRAGMA ignore_check_constraints=ON')
            conn.execute('UPDATE pieces SET king=2 WHERE game_id=? AND x=0 AND y=0',(id,))
        with self.assertRaises(ValueError):self.library.load(id)
        with self.library._connection() as conn:
            conn.execute('PRAGMA ignore_check_constraints=ON')
            conn.execute('UPDATE pieces SET king=0 WHERE game_id=?',(id,))
            conn.execute('UPDATE saved_games SET forced_y=2 WHERE id=?',(id,))
        with self.assertRaises(ValueError):self.library.load(id)


if __name__=='__main__':unittest.main()

    def reset(self, game, editing=False):
        self.search_cancel.set()
        self.search_cancel = Event()
        self.generation += 1
        self.analysis.set('Search statistics appear after the computer decides.')
        self.game,self.editing,self.busy,self.selected=game,editing,False,None
        self.refresh()
        self.schedule_ai()

    def refresh(self):
        moves=[m for m in self.game.legal_moves() if m.start==self.selected] if not self.editing else []
        self.view.render(self.game,self.selected,moves)
        if self.editing:
            text='Setup: choose a brush and click a dark square. Press Start position when ready.'
        elif self.game.winner:
            text=f'{self.game.winner} wins. Start a new game or load a position.'
        else:
            white=sum(p.color=='White' for p in self.game.board.values())
            text=f'{self.game.turn} to move  |  White {white} · Black {len(self.game.board)-white}'
            if self.game.forced is not None:
                text += '  |  Continue the capture with the same piece.'
        self.status.set(text)

    def new_game(self):
        self.reset(Game.standard())

    def custom(self):
        self.reset(Game(),editing=True)

    def start(self):
        if not self.editing:
            return
        if not self.game.board:
            messagebox.showinfo('Empty position','Place at least one piece before starting.')
            return
        self.game.turn=self.setup_turn.get()
        self.game.resolve_terminal()
        self.reset(self.game)

    def is_computer(self):
        return self.opponent.get() == 'Computer '+self.game.turn

    def click(self,square):
        if square is None or self.busy:
            return
        if self.editing:
            if sum(square)%2:
                self.status.set('Pieces belong on dark squares.')
                return
            brush=self.place.get()
            if brush=='Erase':
                self.game.board.pop(square,None)
            else:
                color,rank=brush.split()
                count=sum(p.color==color for sq,p in self.game.board.items() if sq!=square)
                if count>=12:
                    self.status.set('Each player can have at most 12 pieces.')
                    return
                king=rank=='King' or square[1]==(7 if color=='White' else 0)
                self.game.board[square]=Piece(color,king)
            self.refresh()
            return
        if self.game.winner or self.is_computer():
            return
        legal=self.game.legal_moves()
        move=next((m for m in legal if m.start==self.selected and m.end==square),None)
        if move:
            self.animate(move)
        else:
            self.selected=square if any(m.start==square for m in legal) else None
            self.refresh()

    def animate(self,move):
        self.busy=True
        self.selected=move.start
        self.refresh()
        generation=self.generation
        started=time.monotonic()
        def frame():
            if generation!=self.generation:
                return
            fraction=min(1,(time.monotonic()-started)/.24)
            smooth=fraction*fraction*(3-2*fraction)
            a,b=self.view.center(move.start),self.view.center(move.end)
            self.view.position_piece(move.start,(a[0]+(b[0]-a[0])*smooth,a[1]+(b[1]-a[1])*smooth))
            if fraction<1:
                self.root.after(16,frame)
            else:
                self.game.apply(move)
                self.busy=False
                self.selected=self.game.forced
                self.refresh()
                self.schedule_ai()
        frame()

    def schedule_ai(self):
        if self.editing or self.busy or self.game.winner or not self.is_computer():
            return
        generation=self.generation
        def play():
            if generation!=self.generation or self.busy or self.editing or self.game.winner or not self.is_computer():
                return
            self.busy=True
            self.analysis.set('Thinking...')
            snapshot=Game(dict(self.game.board),self.game.turn,self.game.forced,self.game.winner)
            depth=self.depth.get()
            cancel=self.search_cancel
            results=Queue()
            def worker():
                try:
                    results.put(search(snapshot,depth,cancel=cancel))
                except Exception as error:
                    results.put(error)
            Thread(target=worker,daemon=True).start()
            def poll():
                if generation!=self.generation:
                    return
                try:
                    result=results.get_nowait()
                except Empty:
                    self.root.after(20,poll)
                    return
                self.busy=False
                if isinstance(result,Exception):
                    if not isinstance(result,SearchCancelled):
                        self.analysis.set('Search failed; select a mode or start a new game.')
                        messagebox.showerror('Search failed',str(result))
                    return
                self.analysis.set(f'Depth {result.depth} | {result.stats.nodes:,} nodes | '
                                  f'{result.stats.cutoffs:,} cutoffs | {result.stats.elapsed_seconds:.3f}s')
                if result.move is None:
                    self.game.resolve_terminal()
                    self.refresh()
                else:
                    self.animate(result.move)
            poll()
        self.root.after(350,play)

    def close(self):
        self.search_cancel.set()
        self.generation+=1
        self.root.destroy()

    def open_library(self):
        if self.busy or self.editing:
            self.status.set('Finish the move or start your custom position before opening the library.')
            return
        self.search_cancel.set()
        self.search_cancel=Event()
        self.generation+=1
        try:
            LibraryDialog(self,Path(__file__).resolve().parent.parent/'data'/'positions.sqlite3')
        except (OSError,sqlite3.Error,ValueError) as error:
            messagebox.showerror('Unable to open library',str(error))
            self.schedule_ai()

    def load(self):
        path=filedialog.askopenfilename(filetypes=[('Checkers saves','*.json *.txt')])
        if path:
            try:
                game=storage.load(path)
            except (OSError,ValueError,TypeError) as error:
                messagebox.showerror('Unable to load',str(error))
                return
            self.reset(game)

    def save(self):
        if self.busy:
            self.status.set('Wait for the current move to finish before saving.')
            return
        path=filedialog.asksaveasfilename(defaultextension='.json',filetypes=[('Checkers save','*.json')])
        if path:
            try:
                # Setup turn is a UI choice until Start position is pressed.
                game=Game(dict(self.game.board),self.setup_turn.get()) if self.editing else self.game
                storage.save(game,path)
                self.status.set('Game saved.')
            except (OSError,ValueError) as error:
                messagebox.showerror('Unable to save',str(error))

    def resign(self):
        if not self.editing and not self.game.winner and not self.busy:
            self.generation+=1
            self.game.winner='Black' if self.game.turn=='White' else 'White'
            self.game.forced=None
            self.refresh()


def main():
    root=tk.Tk()
    Application(root)
    root.mainloop()


if __name__=='__main__':
    main()
